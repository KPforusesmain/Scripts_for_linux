# linux-tools

Colección de herramientas Linux organizadas por categorías.

## Estructura
- system
- files
- network
- security
- monitoring
- backups
- dev
- text
- automation

## Uso

Dar permisos al generador:
```bash
chmod +x create-linux-tools-structure.sh
```

Ejecutar el generador:
```bash
./create-linux-tools-structure.sh
```

Entrar al proyecto:
```bash
cd linux-tools
```

Ejecutar launcher:
```bash
./launcher.sh
```
